# Global Data Center (GDC) Portal Project

## Project Overview
The **Global Data Center (GDC) Portal Project** is an enterprise-level web application developed for **NTT Communications** and **NTT Limited**, serving data center operations across **Japan (JP)** and **APAC regions**.  
It involves the development and enhancement of multiple interconnected portals that facilitate seamless interaction between customers and providers for data center services.

---

## Portals
- **NCP (Nexcenter Customer Portal)** – Customer-facing portal for JP (NTT Communications) specific operations  
- **NPP (Nexcenter Provider Portal)** – Provider-facing portal for JP (NTT Communications) specific operations  
- **GDCCP (GDC Customer Portal)** – Customer-facing portal for APAC regions  
- **GDCPP (GDC Provider Portal)** – Provider-facing portal for APAC regions  

---

## Key Modules & Features
- **Access Management:** Access Requests, Access Logs, DC-Entry
- **Card Management:** Card Requests, Biometrics  
- **Facility Management:** Facility Requests, Rooms, Data Center Specs  
- **Contact Management:** Data Center Contacts, Customer User Management, Provider User Management  
- **Permissions:** Customer User Permissions, Provider User Permissions  
- **Requests & Orders:** Delivery Requests, Product Orders, Remote Hands  
- **Communication:** Announcements, Email Notifications  
- **Reporting & Monitoring:** History Logs, Monitoring, World Map, Dashboard (Provider)  
- **System Integration:** Customers & Users Sync, Export CSV (MiniWESS), Digital Fabric  
- **Portal Configuration:** Portal Menu, Standards for Nexcenter Portals  
- **Other:** Cabs and Presence, User Guide  

---

## Technology Stack
- **Frontend:** Angular  
- **Backend:** RESTful APIs (Customer API, Provider API, Partner API)  
- **Cloud Platform:** Microsoft Azure  
- **Integration:** Digital Fabric  
- **Legacy Systems:** GLASS (Decommissioned)
