🐍 Python is an interpreted, high‑level language
🔎 Interpreted
Means Python code is not compiled into machine code ahead of time.
Instead, the Python interpreter reads and executes your code line by line at runtime.
This makes development faster and easier (no compilation step), but execution is slower compared to compiled languages like Go or C.
👉 Example: When you run python myscript.py, the interpreter directly executes the script.
---
🔎 High‑Level
Means Python is closer to human language and abstracts away low‑level details.
You don’t need to manage memory manually or deal with hardware instructions.
Provides built‑in data types (lists, dictionaries, strings) and rich libraries.
👉 Example: Writing print(&quot;Hello World&quot;) in Python is simple, while in C you’d need more boilerplate code.
---
🎯 Simple Interview Answer
“Python is called an interpreted, high‑level language because the interpreter runs code directly without compiling, and it provides human‑friendly abstractions so developers don’t worry about low‑level details like memory management.”
